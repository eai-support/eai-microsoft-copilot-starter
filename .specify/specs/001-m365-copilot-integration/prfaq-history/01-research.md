# Research Snapshot

## What Changed

Research separated six meanings of “Copilot integration” and identified a Microsoft 365 agent with narrow PublicAPI V4 tools as the strongest first option.

## Key Decision

The user experience should sit in Microsoft 365 Copilot and Teams, but every EAI read and action must remain behind PublicAPI and Authz. AzureAPI owns Microsoft Graph integration; AICore remains EAI's AI layer.

## Open Review

Select the pilot journey, Microsoft distribution model, identity/federation model, licensed-user scope, and whether EAI data may be indexed into Microsoft 365.
