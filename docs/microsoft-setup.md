# Microsoft Teams And Copilot Setup

## Prerequisites

- Node.js 24 and npm
- EAI CLI and a dedicated development harness tenant
- Microsoft 365 Agents Toolkit access
- A Microsoft 365 development organization with custom app upload and Copilot access enabled
- An EAI External ID OAuth client for this plugin

Do not use a customer tenant for the sample.

## 1. Validate The Public Starter

```bash
npm ci
npm run verify
npm run test:contract
npm run m365:validate
npm run test:business-scenarios
```

The package gate uses `env/package.env`, which contains non-secret validation placeholders only.

## 2. Provision The EAI Harness

```bash
eai login
eai tenant select <development-harness-slug>
eai whoami
eai app provision eai-microsoft-copilot-starter --tenant-id <harness-tenant-id> --format json
eai types validate
eai types diff --tenant-key eai-microsoft-copilot-starter --tenant-id <harness-tenant-id>
eai types seed --tenant-key eai-microsoft-copilot-starter --tenant-id <harness-tenant-id> --format json
eai types diff --tenant-key eai-microsoft-copilot-starter --tenant-id <harness-tenant-id>
eai provision entra --force --redirect-uri https://teams.microsoft.com/api/platform/v1.0/oAuthRedirect
npm run m365:configure:dev
```

The last command reads the EAI-generated OAuth settings from the ignored `.env.local` file and writes them to ignored `env/.env.dev.user` with owner-only permissions. It also preserves any Microsoft identifiers generated by an earlier toolkit run and never prints the client secret.

Stop if the selected tenant is not a dedicated test harness or if schema drift remains.

## 3. Configure OAuth And PublicAPI

Run `npm run m365:configure:dev` whenever EAI OAuth settings change. The command creates the ignored `env/.env.dev` runtime file when needed and manages the local `env/.env.dev.user` file; do not copy live tenant, app or secret values into tracked files.

Set:

- `EAI_PUBLIC_API_URL` to the harness tenant's regional PublicAPI base URL.
- `EAI_TENANT_ID` to the harness tenant ID.
- `EAI_AUTHORIZATION_URL` and `EAI_TOKEN_URL` to the EAI External ID authorization-code endpoints.
- `EAI_OAUTH_SCOPE` to the delegated PublicAPI scope.
- `EAI_OAUTH_CLIENT_ID` to the plugin OAuth client.

The OAuth client must allow Microsoft's redirect URI `https://teams.microsoft.com/api/platform/v1.0/oAuthRedirect`. This is an identity registration change and should be reviewed through the EAI-owned app provisioning process rather than added ad hoc to an unrelated registration.

## 4. Provision And Preview

```bash
npx atk auth login m365
npx atk provision --env dev
npx atk preview --env dev
```

Confirm the signed-in Microsoft account reports both custom app upload and Copilot access. Exercise list and get first, then create and update with the visible confirmation prompts.

## 5. Publish For Organization Review

```bash
npx atk publish --env dev
```

Publishing submits the package to the Microsoft organization catalog. It does not bypass Microsoft admin review or EAI tenant authorization.
